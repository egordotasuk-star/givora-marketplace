# Givora — unified virtual inventory update

## Что добавлено
- Отдельная вкладка «Инвентарь» с разделами «Мои подарки» и «На продаже».
- Выдача виртуальной карточки подарка администратором по Telegram ID или @username, с названием и HTTPS-картинкой.
- Выставление подарка из инвентаря по цене в Givora Stars. SQL-функция блокирует повторную публикацию.
- Начисление внутренних Givora Stars администратором через защищённую SQL-функцию.
- Подтверждение заказа/возврат через атомарную SQL-функцию; при подтверждении виртуальная карточка поступает получателю, объявление снимается с продажи.
- Просмотр промокодов, числа активаций, лимита и отключение промокода.

## Установка
1. Сделай резервную копию текущего репозитория и Supabase.
2. В Supabase SQL Editor выполни **полностью** файл `supabase/migrations/002_givora_unified_features.sql`.
3. В Supabase Edge Functions → `givora-api` замени код файлом `supabase/functions/givora-api/index.ts` и нажми Deploy.
4. В GitHub обнови файлы проекта из архива (сохрани действующий `config.js` с публичными Supabase URL и anon/publishable key).
5. Дождись автоматического деплоя Render и проверь Mini App.

## Важно
- Не публикуй `BOT_TOKEN` или `SUPABASE_SERVICE_ROLE_KEY`. Они должны оставаться только в Supabase Secrets.
- Givora Stars — внутренние тестовые баллы; этот комплект не подключает реальные платежи и не передаёт реальные Telegram NFT.
- Получатель должен хотя бы раз открыть Mini App, чтобы его профиль появился в `profiles`.
- Существующая SQL-функция покупки должна быть обновлена миграцией; миграция делает объявление недоступным сразу после создания заказа, чтобы избежать двойной покупки.
- Перед обновлением проверь проект на тестовой копии. В коде сохранены текущие основные страницы и дизайн.
