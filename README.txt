GIVORA v7 — DEMO BUILD

Что изменено:
- В DEMO-предпросмотр добавлен администратор @harmonydurov. В профиле есть отдельная кнопка GOD MODE.
- В Telegram Mini App username читается из Telegram WebApp user data.
- В обычном браузере для предпросмотра автоматически используется @harmonydurov.
- Курс TON/USD загружается через CoinGecko, TON/USDT — через Binance. Есть резервный пересчёт, если доступен только один источник.
- Калькулятор показывает результаты и для USD, и для USDT; добавлены подписи источников и времени обновления.
- Добавлено пояснение по Stars: единого публичного рыночного курса Stars к TON/USD нет; тестовый баланс не означает реальное пополнение.

ВАЖНО:
Это по-прежнему только frontend DEMO. GOD MODE в этой версии не является безопасной авторизацией: проверка username в браузере не защищает админку. В обычном браузере предпросмотр специально открывает демо-админку для @harmonydurov, поэтому любой посетитель может изучить интерфейс и локальные функции.
Данные сохраняются только в localStorage текущего браузера и не синхронизируются между пользователями или устройствами.
Не подключены: настоящий Telegram-бот, сервер, защищённая админ-роль, уведомления админу, проверка фактического получения подарка, реальные платежи, покупка/пополнение Stars, TON-кошелёк и live-синхронизация.
Не отправляй реальные подарки и не используй реальные деньги в этой демо-версии.

Для production нужен backend с проверкой Telegram initData на сервере и админ-ролью, назначенной на сервере. Не размещай секреты и bot token в frontend.
